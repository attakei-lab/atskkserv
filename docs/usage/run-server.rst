==============
サーバーの起動
==============

ここでは、基本的なサーバー起動の方法を説明します。

CLI上での呼び出し
=================

サーバーモードでの起動には ``serve`` サブコマンドを使用します。

.. code:: console

   atskkserv serve

使用する辞書ファイルのパスはデフォルトだと :doc:`./build-dictionary` での出力先のデフォルト値と同じになっています。
そのため、どちらも引数での指定がなければ、生成した辞書ファイルをそのまま使用できます。

サーバーを起動したら、SKK IME側でサーバー接続の設定を行うことで、変換時に必要に応じてサーバーとの通信を行うようになります。
