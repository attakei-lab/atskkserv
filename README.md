# atskkserv

attakei's skkserv

> このプロジェクトは取り扱う内容の性質から、
> いくつかの事項を除いて「標準自然言語」として "日本語" を採用しています。
>
> ただし、将来にあるかもしれないわずかな可能性を念のため考慮して、
> いくつかの事項に限り「システム自然言語」として "英語" を採用しています。
>
> - "Gitのコミットメッセージ"のような不可逆に近いテキスト
> - CLIツール系が標準出力/標準エラー出力にアウトプットする可能性があるテキスト [^1]
>
> なお、自動生成されるテキストは原則として出力されたままを採用します。


Nim言語製のSKK辞書サーバーです。

主目的を次の3条項をコアコンセプトにしています。 [^2]

- 自分が普段使いしているツールを
- 自分がコントロールしやすい言語で
- 自分の環境向けの機能を中心に

[^1]: プロダクトだけでなく、開発補助ツールも該当する。
[^2]: 実行時の速度を優先するため、PythonではなくNimを採用しています。

## 開発関連

開発作業には、主に下記の3実行環境を標準としています。

- Nim: プロダクトコード本体。
- Python: ドキュメントの生成環境
- Bun: 日本語の品質担保(textlintの実行環境としてのみ使用)

CLI管理にaquaを使用している場合は、下記のコマンドで一通りのことが準備可能となっています。

```console
aqua i
task setup
```
